# Release notes

One file per released version, kept so the reasoning behind a release survives
after the next one replaces the root `RELEASE_NOTES.md`.

| Version | Notes |
|---|---|
| v0.1.1 | [`../../RELEASE_NOTES.md`](../../RELEASE_NOTES.md) — current |
| v0.1.0 | [`v0.1.0.md`](v0.1.0.md) — first release |

The root `RELEASE_NOTES.md` always describes the version being cut; the release
workflow uses it as the body of the GitHub release and ships it inside every
archive. When a version is superseded, its notes move here.
